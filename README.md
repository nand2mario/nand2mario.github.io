# Small Things Retro

The source for nand2mario.github.io. A small Python generator builds the blog,
projects and wiki into `public/`. There is no Hugo dependency.

## Build and preview

```sh
python3 -m pip install -r requirements.txt
python3 -m unittest discover -s bin -p 'test_*.py'
python3 bin/generate.py
python3 -m http.server 8000 --directory public
```

Open http://localhost:8000/. The generator replaces `public/` on each build.
GitHub Actions builds and deploys the site when changes reach `main`.

## Content and templates

- `content/posts/`: dated blog posts, generally `YEAR/slug/index.md` with assets
  alongside. Existing `{{< include "file.md" >}}` directives are expanded by
  Python; they do not require Hugo.
- `content/projects/`: project pages.
- `content/wiki/`: recursive wiki pages and their assets.
- `bin/templates/`: the active HTML templates and CSS.
- `static/`: files copied to the output root.

## Editing the wiki

The wiki is a collection of Markdown files maintained by nand2mario through
Git. Its entry point is `content/wiki/index.md`, published at `/wiki/`.
For example, `content/wiki/p6/roms.md` becomes `/wiki/p6/roms/`.
Nested `index.md` pages become section landing pages: `p6/index.md` maps to
`/wiki/p6/`. Do not create both `p6.md` and `p6/index.md`; their URLs collide.

Use optional YAML frontmatter for the title and an explicit update date:

```markdown
---
title: My research note
updated: 2026-09-13
---

An introduction.

[TOC]

## A section

[Related page](other.md#details)
![A diagram](images/diagram.jpg)
```

Use normal Markdown links, relative to the **source file**. From `p6/roms.md`,
`../index.md` links to the wiki home, and `pentium2_rom_candidates.jpg` loads
the image beside that Markdown file. The generator rewrites both to their
published URLs, preserving query strings and heading anchors. Absolute links
outside `/wiki/` and external URLs are left alone. Use Markdown syntax for
wiki links and images; raw HTML URL attributes are not rewritten.

The generator checks local wiki page/asset targets and rejects missing targets
and duplicate page URLs. Heading anchors are generated by Python-Markdown's
TOC extension; `[TOC]` inserts an optional table of contents. Pages marked
`draft: true` are not generated. Keep private notes and unused assets outside
`content/wiki/`: all non-Markdown assets there are copied to the public wiki.

Wiki pages are independent of the dated blog feed and have no browser editor
or comment widget. Add links to `index.md` as new topics become useful.
